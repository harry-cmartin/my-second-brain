# Java e sua história

Interessada em dispositivos eletrônicos inteligentes, a Sun Microsystems financiou uma pesquisa interna com o codinome Green em 1991. O projeto resultou no desenvolvimento de uma linguagem baseada em C e C++ que seu criador, James Gosling, chamou de Oak (carvalho) em homenagem a uma árvore que dava para a janela do seu escritório na Sun

![Logo java](../../assets/images/javalogo.png)

Descobriu-se mais tarde que já havia uma linguagem de computador chamada Oak. Quando uma equipe da Sun visitou uma cafeteria local, o nome Java (cidade de origem de um tipo de café importado) foi sugerido e pegou.

Mas o projeto Green atravessava algumas dificuldades. O mercado para dispositivos eletrônicos inteligentes destinados ao consumidor final não estava se desenvolvendo tão rapidamente como a Sun tinha previsto. Pior ainda, um contrato importante pelo qual a Sun competia fora concedido a outra empresa. Então, o projeto estava em risco de cancelamento. Por pura sorte, a World Wide Web explodiu em popularidade em 1993 e as pessoas da Sun viram o imediato potencial de utilizar Java para criar páginas da Web com o chamado conteúdo dinâmico. Isso deu nova vida ao projeto.

Em maio de 1995, a Sun anunciou Java formalmente em uma conferência importante. Normalmente, um evento como esse não teria gerado muita atenção. Entretanto, Java gerou interesse imediato na comunidade comercial por causa do fenomenal interesse pela World Wide Web.

### **Java é agora utilizada praticamente em todo lugar**:


- Páginas da Web com conteúdo interativo e dinâmico;

- Aplicações corporativas de grande porte;

- Softwares destinados ao consumidor final.

- Aplicativos para Smartphones.


| Versão | Data de Lançamento | Principais Recursos / Novidades |
|---------|-------------------|---------------------------------|
| JDK 1.0 | 23/01/1996 | Primeira versão do Java. Atualmente utilizada principalmente para compatibilidade com navegadores antigos. |
| JDK 1.1 | 19/02/1997 | Introdução de bibliotecas importantes como Java RMI, JavaBeans, novo modelo de eventos e JDBC para acesso a bancos de dados. |
| J2SE 1.2 | 08/12/1998 | Grande expansão da biblioteca padrão (Java API), aumentando significativamente o número de classes disponíveis. |
| J2SE 1.3 | 08/05/2000 | Inclusão de bibliotecas como JNDI e JavaSound, entre outras melhorias. |
| J2SE 1.4 | 06/02/2002 | Introdução da palavra-chave `assert`, biblioteca NIO (New I/O) e outras melhorias. |
| J2SE 5.0 | 30/09/2004 | Generics, Enum, Auto-boxing, Enhanced For (`for-each`) e diversas melhorias na linguagem. |
| Java SE 6 | 11/12/2006 | Melhorias significativas de desempenho e estabilidade, além de avanços no compilador JIT (Just-In-Time). |
| Java SE 7 | 28/07/2011 | Suporte a `String` no `switch`, operador diamante (`<>`), melhorias em VarArgs e inferência de tipos genéricos. |
| Java SE 8 | 18/03/2014 | Expressões Lambda, Stream API, `forEach`, interfaces funcionais, Default Methods e Method References. |
| Java SE 9 | 21/09/2017 | Introdução dos Factory Methods para coleções e do sistema de módulos (Project Jigsaw). |
| Java SE 10 | 20/03/2018 | Inferência de tipos com `var` e melhorias na criação de coleções imutáveis. |
| Java SE 11 (LTS) | 25/09/2018 | Métodos `readString()` e `writeString()`, novos métodos para Strings (`repeat`, `strip`, `lines`, `isBlank`) e suporte ampliado ao `var`. |
| Java SE 12 | 19/03/2019 | Melhorias nas Switch Expressions e inclusão dos métodos `indent()` e `transform()` para Strings. |
| Java SE 13 | 17/09/2019 | Introdução do `yield` em Switch Expressions e Text Blocks (preview) para Strings multilinha. |
| Java SE 14 | 17/03/2020 | Helpful NullPointerExceptions, Records (preview) e Switch Expressions como recurso oficial. |
| Java SE 15 | 09/2020 | Diversos aprimoramentos, recursos em preview, remoções de APIs obsoletas e redução do tamanho do JDK. |
| Java SE 16 | 03/2021 | Melhorias em desempenho, memória, ZGC, Metaspace, JVM e novas APIs. |
| Java SE 17 (LTS) | 09/2021 | Filtros de desserialização por contexto, Pattern Matching para `switch` (preview) e melhorias de segurança e desempenho. |
